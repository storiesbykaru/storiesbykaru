Stories by Karu — Visual Editor V2

Open index.html to view the site. Open editor.html to edit it.

Header brand and hero brand are now independent and each can be switched between TEXT and LOGO.
- Header: small top-left brand, with editable text/logo + logo size.
- Hero: large main brand, with editable text/logo + logo size.
- Upload different logo files for header and hero if desired.

Changes are saved in this browser using localStorage; this is a local editor prototype, not a cloud CMS.
